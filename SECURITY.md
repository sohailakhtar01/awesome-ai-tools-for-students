# 🔒 Security Policy

## Scope

This is a **curated list repository** — it contains only Markdown files and no executable code. There is no application, API, or infrastructure to attack.

However, we take the following security-related concerns seriously:

---

## Reporting Malicious or Harmful Tools

If you discover that a tool listed in this repository:

- Has been found to engage in **data harvesting, privacy violations, or malicious behavior**
- Has been **taken over by a bad actor** since our last review
- Contains **malware, phishing, or deceptive practices**
- Has received a **significant security incident disclosure**

Please report it immediately.

### How to Report

**For urgent, sensitive disclosures:**
📧 Email: **[sohail@thetoolsverse.com]** with the subject line `[SECURITY] Tool Report: [Tool Name]`

**For non-urgent reports:**
Open a [GitHub Issue](../../issues/new) using the "Security Report" label.

Please include:
- The tool name and section in the README
- A description of the concern
- Links to sources confirming the issue (CVE, news reports, official disclosure, etc.)

---

## What Happens After You Report

1. We will acknowledge your report within **48 hours**
2. We will investigate and verify the claim within **7 days**
3. If verified, the tool will be **removed or flagged** in the repository
4. We will credit you in the resolution (unless you prefer anonymity)

---

## Responsible Disclosure for the Repository Itself

While this repo doesn't contain code, if you discover a way our repository structure, GitHub Actions (if any), or associated infrastructure could be misused:

- Please disclose privately via email before opening a public issue
- Give us **14 days** to address the concern before public disclosure
- We commit to responding promptly and transparently

---

## Privacy Note for Contributors

We do not collect personal data from contributors beyond what GitHub provides as part of pull request and issue submission. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

---

## Out of Scope

The following are **not security issues** for this repository:

- Typos or formatting errors (open a regular issue or PR)
- Disagreements about tool rankings or inclusion (open a discussion)
- Outdated pricing information (open a PR with updated info)
