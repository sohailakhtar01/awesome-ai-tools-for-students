## Before You Submit

Please take 5 minutes to:

1. **Search existing entries** — the tool may already be listed
2. **Read the README** — understand the scope and quality bar of this list
3. **Verify the tool still works** — test it yourself before submitting
4. **Check the tool's pricing** — free tier claims must be accurate at time of submission

---

## What Makes a Good Tool Submission

We accept tools that meet **all** of the following criteria:

### ✅ Eligibility Checklist

- [ ] The tool is **actively maintained** (updated within the last 12 months)
- [ ] The tool has a **clear, real use case for students** (not just "general AI")
- [ ] The tool's **free tier is real** — not a 3-day trial with credit card required
- [ ] The tool is **legally accessible** in most countries
- [ ] The tool is **not already listed** in the repository
- [ ] The tool provides **genuine value** that isn't already covered by an existing listing
- [ ] You have **personally used** the tool and can speak to its quality

### 🌟 What We Prioritize

- Tools with **verified student discounts** or free plans
- Tools that **address a specific academic use case** not well-covered by existing entries
- Tools with a track record of **reliability and trust**
- Tools that have **transparent privacy policies**

---

## What We Won't Accept

The following will be rejected without review:

- ❌ Tools you're affiliated with (founder, employee, affiliate) without clear disclosure
- ❌ Tools with no legitimate free tier or student access path
- ❌ Duplicate tools that don't meaningfully differ from existing entries
- ❌ Tools with documented privacy violations or data misuse
- ❌ Tools abandoned or not updated in 12+ months
- ❌ Tools that primarily generate academic content for submission (AI essay mills)
- ❌ Purely promotional submissions with no honest limitations section
- ❌ Requests to change rankings or top picks without data-backed justification

## How to Submit a Tool

### Option 1: Pull Request (Preferred)

1. Fork this repository
2. Add your tool to the correct category section
3. Use the existing format (table + description + pros/limitations)
4. Only suggest real, actively maintained tools
5. Disclose if you have any affiliation with the tool
6. Submit a Pull Request with a clear description

### Option 2: GitHub Issue

If you're not comfortable with pull requests, open a [GitHub Issue](../../issues/new) using the "Tool Suggestion" template and we'll review it.

## Entry Format

All tool entries must follow this exact format. Incomplete entries will be returned for revision.

````markdown
#### 🟡 [Tool Name]
**by [Company/Creator]** · [toolname.com](https://toolname.com)

One to two sentences describing what this tool does and what makes it useful for students specifically. Be factual and specific — avoid marketing language.

| Attribute | Details |
|-----------|---------|
| **Free Tier** | ✅ Yes — [what's included] / ❌ No — [paid only] |
| **Paid Plan** | [Plan name] ([price]) — [what's added] |
| **Best For** | [2–4 specific use cases] |
| **Beginner Friendly** | ✅ Yes / 🟡 Moderate / ❌ Advanced |
| **Student Use Cases** | [3–4 realistic student scenarios] |

**Pros:**
- [Specific, honest benefit]
- [Specific, honest benefit]
- [Specific, honest benefit]

**Limitations:**
- [Honest limitation — every tool has them]
- [Honest limitation]
````

### Color Coding Convention

Use these emoji colors to indicate tool "type" for visual scanning:

| Color | Meaning |
|-------|---------|
| 🔵 | Best-in-class / Most recommended |
| 🟢 | Excellent, strong second choice |
| 🟡 | Good, with notable caveats |
| 🟠 | Specialized, niche but valuable |
| ⚪ | Simple / Classic tool |

## Updating Existing Entries

If a tool's pricing, features, or free tier has changed:

1. Open a Pull Request with the updated information
2. Link to the official source confirming the change (pricing page, changelog, etc.)
3. Note the date of the change in your PR description

Pricing and feature changes happen frequently. We appreciate contributors who keep entries current.

---

## Reporting Issues

Found a broken link? Outdated pricing? A tool that's shut down?

Please open a [GitHub Issue](../../issues/new) with:
- The tool name and section
- What's wrong (broken link, wrong price, tool defunct, etc.)
- A source confirming the correct information (if applicable)

---

## Review Process

Pull requests are reviewed by maintainers within **7–14 days**. We will:

- ✅ Merge if the entry meets all criteria and format requirements
- 🔄 Request changes if formatting is off or information is incomplete
- ❌ Close if the tool doesn't meet eligibility criteria (with an explanation)

Please don't take rejections personally. We have to maintain a quality bar to keep the list genuinely useful.

---

## Disclosure Requirement

If you have **any affiliation** with a tool you're submitting — as an employee, founder, investor, or paid affiliate — you **must disclose this** in your PR description.

Undisclosed affiliated submissions will be permanently rejected and the contributor noted.

This is not about penalizing affiliates — it's about keeping the list credible.
